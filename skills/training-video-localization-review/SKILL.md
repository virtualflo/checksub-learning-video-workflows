# Training video localization review

Turn the supplied lesson, transcript and target-language requirements into a reviewable localization handoff. Work with the material and tools the user has chosen.

## Review the brief

Identify the authoritative source version, target locales, intended learners, destination player or LMS, and required outputs. A locale such as fr-CA can imply terminology and spelling decisions beyond a language label. Mark absent information as unknown. Ask only when it changes the next useful action.

Extract terms that can change the lesson's meaning, especially product labels, job roles, numbers, units, negation, deadlines and safety instructions. Preserve exact UI labels where learners must find them on screen. Identify on-screen text separately from spoken text because translating one does not update the other.

Map each locale to its subject-matter reviewer, linguistic reviewer and delivery requirement when those roles are known. Distinguish a proposed reviewer from someone who has actually accepted or approved work. Preserve any approvals already supplied by the user.

## Produce the handoff

Give the user a short list of consequential ambiguities and the next practical action for each. Use [assets/locale-review.csv](assets/locale-review.csv) when a reusable tracking file helps. Add rows for source segments and locales that genuinely need review. Keep resolved information and unknowns distinct.

A useful handoff identifies the source evidence, proposed translation decision, affected locale, reviewer status and output artifact. Avoid marking a translation reviewed based only on fluent wording. If the source video is unavailable, explain which visual or timing questions require it.
