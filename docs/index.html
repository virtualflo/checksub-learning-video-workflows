How to use the examples

      
Each case includes its fictional source, candidate subtitles and an explained alternative. Timing exercises use the stated source intervals. Language exercises require comparison with the source meaning. Editorial choices depend on your audience and delivery player.

      
The format references are the W3C WebVTT Candidate Recommendation Draft and the Library of Congress SubRip format description. Reading-speed thresholds in the exercises are explicit editorial assumptions.
