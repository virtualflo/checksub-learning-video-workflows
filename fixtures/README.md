# Synthetic caption review cases

Eight original teaching cases published by Checksub under MIT. The single source of case data is manifest.json. Candidate and reviewed-example files are generated from it. The browser lab uses an identical copy of the manifest.

Use the supplied source context to assess each candidate. Cases include format defects, editorial review choices and semantic translation changes. An overlap can represent simultaneous speech. Correct reading speed depends on the intended delivery context.

These fictional cases were prepared with AI assistance. They contain no customer media and provide no comparative score for Checksub or other vendors. The corpus does not establish automated semantic accuracy, legal compliance or real LMS playback.

Sources and explicit assumptions are included in the manifest. The WebVTT source is a W3C Candidate Recommendation Draft. The Library of Congress describes SubRip structure and its limited standardization.

To propose an additional original public case, use the repository caption-case issue form.
